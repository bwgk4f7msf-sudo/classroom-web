## 升级配置与兼容性

- 同时更新前后端并重启 API。旧会话缺少创建时间，升级后须重新登录；旧验证码及重启前验证码须刷新。
- 首次创建管理员必须设置 ADMIN_PASSWORD，已有管理员密码不变。历史 admin-credentials.txt 不自动删除；确认已改密后清理该文件与相关备份。
- TRUST_PROXY=1 必须配套 TRUSTED_PROXIES，Compose 也要求填写。使用代理实际来源地址，避免全网段；代理覆盖 X-Forwarded-For/Proto/Host，并从网络层限制 API 入口。
- SQLite 保持原有数据；MySQL 启动时将验证码字段从 VARCHAR(10) 扩为 VARCHAR(64)，数据库账号需要 ALTER 权限。
- 注册接口（含旧别名）由 201 / 409 改为统一 202；外部客户端须按新受理语义处理。
- 限流为单进程内存计数，重启会清零；多副本部署须使用共享限流服务或网关。密码重置的 24 小时限制与待办去重持久化在数据库中。
- 学生查询支持部分学号或姓名，教师仅能为自己的有效教学班添加学生。
- Vite 开发页面由开发服务器提供；生产页面的响应头由 Express 设置。真实代理与 MySQL 环境仍须部署后验证。
